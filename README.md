# Facial Emotion Recognition using Machine Learning

## Overview

This project presents a Machine Learning-based Facial Emotion Recognition system developed using **Java** and **OpenCV**. The system detects human faces from live webcam input or images and classifies facial expressions into different emotions. It demonstrates the practical application of Computer Vision and Machine Learning for real-time emotion analysis.

## Features

- Real-time face detection
- Facial emotion recognition
- Webcam support
- Image preprocessing
- Machine Learning-based classification
- Easy-to-use interface

## Technologies Used

- Java
- OpenCV
- Machine Learning
- Support Vector Machine (SVM)
- Haar Cascade Classifier

## Workflow

1. Capture image from webcam.
2. Convert image to grayscale.
3. Detect face using Haar Cascade.
4. Extract facial features.
5. Predict emotion using the SVM model.
6. Display the detected emotion.
